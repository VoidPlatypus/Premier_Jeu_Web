Passage dans l'ombre

Le Système t'alerte : une activité anormale sur le pare-feu principal. Quelqu'un tente une élévation de privilèges depuis l'intérieur du réseau. Tu dois écrire un script de détection en urgence pour isoler le compte compromis avant qu'il n'atteigne le serveur de base de données.

Le Système te propose un script automatique pré-rempli... mais il semble généré à la hâte. L'utiliser comporte un risque de bug critique.

Écrire ton propre script (plus lent, plus sûr) Utiliser le script du Système (rapide, risqué)
